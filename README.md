
# 週案メーカー

先生向けの週案作成Webツールです。

## できること

週ごとの予定を表形式で作成し、教科・単元名・授業メモ・行事・朝の予定・昼の予定・持ち物・下校時刻・お知らせを入力できます。

左側に週案の完成形を大きく表示し、右側の編集パネルから選択したマスを詳しく入力できます。教科と単元名を入れると、週案のマスへすぐ反映されます。

表示する曜日、1〜8時間目の表示、朝・中休み・給食・昼休み・持ち物・下校・お知らせなどの行は個別に表示／非表示を切り替えられます。行の表示名を変えたり、上下ボタンで順番を変えたりできます。学校独自の「そうじ」「帰りの会」「昼休み2」などは、文字入力の行や時刻の行として追加・削除できます。追加した行の内容は日付ごとに保存され、削除時はその行の入力内容も削除することを確認します。

入力した授業から、今週の教科別時数と合計時数を自動集計します。表示中の授業時数を基準に集計するため、6時間目を非表示にした場合も集計から外れます。

週案は端末内に自動保存されます。JSON形式で書き出し・読み込みができ、現在の週をデータ入りURLとして共有することもできます。共有はサーバーへ保存する方式ではなく、URLのハッシュにデータを入れる方式です。共有URLを開くと読み取り専用プレビューになり、閲覧する端末の保存データは上書きしません。URLには学校名・先生名・学級名や週案の内容が含まれるため、共有相手と共有範囲を確認してから送ってください。JSON読み込みではファイルの形式を検証し、現在の週案を置き換える前に確認を表示します。

印刷を前提にレイアウトを組み、A4縦・A4横を切り替えられます。

毎週くり返す教科は「時間割登録」で曜日×時限の時間割として登録できます。登録した時間割を今週へ反映すると、すでに入力されているコマを残したまま、空いているコマへ教科だけを自動入力できます。単元名や授業メモは週案側で後から入力できます。単元名の入力欄には、保存済みの週案で過去に使った単元名が候補として表示されるため、前の週の単元名を再利用しやすくなっています。

## ファイル構成

index.html は表示の骨組みです。
styles.css は画面表示と印刷用CSSです。
js/data.js は教科・行・週案データの定義です。
js/state.js は自動保存と週の状態管理です。
js/render.js は週案と集計表示を担当します。
js/editor.js はセル編集と表示設定を担当します。
js/file.js はJSON書き出し・読み込みを担当します。
js/share.js は共有URLの生成・読み込みを担当します。
js/app.js は起動と全体イベントを担当します。

外部APIやバックエンドを使わない静的Webアプリとして構成しています。画面のトーンはEDU-KITのeditorial系設計と既存のedu-effectsの考え方を参考に、管理画面として落ち着きがありつつ、紙面らしい温度感を持たせています。

[GitHub Pagesで開く](https://tt-sensei.github.io/jisukakuninkun/)



## Google Driveでの保管

別の端末でも同じ週案を使いたい場合は、Google DriveをJSONデータの保管場所として利用できます。

設定画面の「Google Drive」に共有・保管用フォルダのURLを登録すると、週案メーカーからそのフォルダを開けます。

使い方は「書き出し」→ JSONファイルをGoogle Driveへ保存 → 別の端末でGoogle DriveからJSONをダウンロード → 「読み込み」です。

この方式ではGoogle Drive APIやGoogleログインをアプリへ組み込まないため、Google Cloud側の認証設定は不要です。Driveの権限管理はGoogle Drive側で行います。

「週案メーカー」からGoogle Driveへ自動アップロードする機能ではありません。直接アップロードまで自動化する場合は、Google Drive APIとOAuth 2.0の設定が必要になります。

## 年間予定

年間予定画面から「行事」「祝日」を日付または期間で登録できます。

- 年間予定は週案とは別に保存され、週を移動しても保持されます。
- 登録した行事は、該当週の「行事予定」欄に自動表示されます。
- 祝日は該当日の全コマを休日として表示し、斜線の入った終日表示になります。
- 年間予定は現在の週案データを書き換えずに参照表示するため、年間予定を変更すると該当週へ自動反映されます。

## 回帰テスト

Node.js 20以降がある開発環境では、次のコマンドでデータ正規化・JSON読み込み検証・共有URLの保存保護を確認できます。

`node --test tests/regression.test.cjs`

テスト用コードは開発時のみ使用し、公開サイトの動作には追加ライブラリやビルド工程は必要ありません。


### 月・年度の時数集計
- 保存済みの週案から、選択中の週が属する月の時数と、4月始まりの年度累計を集計します。
- 欠課・年間予定で登録した祝日・表示対象外の曜日や時間目は集計しません。
- 集計はこの端末に保存されている週案データを対象とし、未入力の授業は数えません。


### 年間標準時数との比較
- 「週案の設定」で教科ごとの年間標準時数を登録できます。空欄の教科は比較対象にしません。
- 週案の保存データから集計した年度累計と、登録した標準時数・残り時間を確認できます。
- 年間標準時数は学校・学年の設定に合わせて入力してください。初期値は未設定です。
