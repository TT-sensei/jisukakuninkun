
# 週案メーカー

先生向けの週案作成Webツールです。

## できること

週ごとの予定を表形式で作成し、教科・単元名・授業メモ・行事・朝の予定・昼の予定・持ち物・下校時刻・お知らせを入力できます。

左側に週案の完成形を大きく表示し、右側の編集パネルから選択したマスを詳しく入力できます。教科と単元名を入れると、週案のマスへすぐ反映されます。

表示する曜日、1〜8時間目の表示、朝・昼・持ち物・下校・お知らせなどの行は個別に表示／非表示を切り替えられます。よく使う行は表示名も変更できます。

入力した授業から、今週の教科別時数と合計時数を自動集計します。表示中の授業時数を基準に集計するため、6時間目を非表示にした場合も集計から外れます。

週案は端末内に自動保存されます。JSON形式で書き出し・読み込みができ、現在の週をデータ入りURLとして共有することもできます。共有はサーバーへ保存する方式ではなく、URLのハッシュにデータを入れる方式です。

印刷を前提にレイアウトを組み、A4縦・A4横を切り替えられます。

毎週くり返す教科は「時間割登録」で曜日×時限の時間割として登録できます。登録した時間割を今週へ反映すると、すでに入力されているコマを残したまま、空いているコマへ教科だけを自動入力できます。単元名や授業メモは週案側で後から入力できます。

## ファイル構成

index.html は表示の骨組みです。
styles.css は画面表示と印刷用CSSです。
js/data.js は教科・行・週案データの定義です。
js/state.js は自動保存と週の状態管理です。
js/render.js は週案と集計表示を担当します。
js/editor.js はセル編集と表示設定を担当します。
js/file.js はJSON書き出し・読み込みを担当します。
js/share.js は共有URLの生成・読み込みを担当します。
js/app.js は起動と全体イベントを担当します。

外部APIやバックエンドを使わない静的Webアプリとして構成しています。画面のトーンはEDU-KITのeditorial系設計と既存のedu-effectsの考え方を参考に、管理画面として落ち着きがありつつ、紙面らしい温度感を持たせています。

[GitHub Pagesで開く](https://tt-sensei.github.io/jisukakuninkun/)


## 年間予定

年間予定画面から「行事」「祝日」を日付または期間で登録できます。

- 年間予定は週案とは別に保存され、週を移動しても保持されます。
- 登録した行事は、該当週の「行事予定」欄に自動表示されます。
- 祝日は該当日の全コマを休日として表示し、斜線の入った終日表示になります。
- 年間予定は現在の週案データを書き換えずに参照表示するため、年間予定を変更すると該当週へ自動反映されます。
