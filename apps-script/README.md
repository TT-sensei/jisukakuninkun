# 週案メーカー Google同期用 Apps Script

このフォルダは、GitHub Pages版の「週案メーカー」から呼び出すGoogle Apps Script側のコードです。

## 保存方式

週案そのものはGitHubには保存しません。

Apps ScriptのUser Propertiesへ、Googleアカウントごとに週案データを保存します。User Propertiesはユーザー単位で分離されるため、同じApps Scriptを使っても別のGoogleアカウントの週案を読み出すことはできません。

## 初回設定

1. Google Apps Scriptで新しいスタンドアロンプロジェクトを作成します。
2. このフォルダの `Code.gs`、`Index.html`、`appsscript.json` の内容を、それぞれ同名ファイルへ貼り付けます。
3. Apps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」で、次のプロパティを1つ登録します。

`ALLOWED_EMAILS`

値は、週案メーカーとの同期を許可するGoogleアカウントのメールアドレスです。複数アカウントを許可する場合はカンマ区切りにします。

例：

`example@gmail.com`

4. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」を選びます。
5. 「実行するユーザー」は「ウェブアプリにアクセスしているユーザー」にします。
6. 「アクセスできるユーザー」は、用途に応じて「Googleアカウントを持つ全員」または学校のGoogle Workspaceドメインに限定します。
7. デプロイして発行された `/exec` のURLをコピーします。
8. 週案メーカーの「設定」→「クラウド同期」に、そのURLを貼り付けます。
9. 「Googleアカウントを確認」で接続すると、現在接続したGoogleアカウントが画面に表示されます。

## セキュリティ

- GitHub側にはGoogleのパスワードやアクセストークンを保存しません。
- Google同期サーバー側で許可アカウントをチェックします。
- 保存データはUser Propertiesへアカウント単位で保存します。
- Google Drive全体を読む権限やGmail権限は使いません。
- 週案データは圧縮して分割保存します。
- GitHub Pages側とApps Script側の通信には、接続元を確認するpostMessageとワンタイムnonceを使います。

## 注意

Apps Scriptのウェブアプリでは、複数のGoogleアカウントへ同時ログインしているとアカウント選択が意図どおりにならない場合があります。学校用と個人用を切り替えるときは、ブラウザのアカウントを1つにするか、別ウィンドウ／シークレットウィンドウを使う運用が安全です。
